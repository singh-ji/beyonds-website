# BeyondShift website

Single-page marketing website for BeyondShift, built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

The main page is in `app/page.tsx`, global styles are in `app/globals.css`, and public brand assets are in `public/`.
